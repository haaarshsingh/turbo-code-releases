# Turbo Code

Downloads for Turbo Code, a desktop app for directing AI coding agents on your Mac.

**[Download the latest version](https://github.com/haaarshsingh/turbo-code-releases/releases/latest)**: the `.dmg` file, for Macs with Apple silicon (M1 or newer) on macOS 13 or later.

Open the DMG and drag Turbo Code (Alpha) into Applications. The first time you open it, approve it in **System Settings → Privacy & Security → Open Anyway**. After that, Turbo Code updates itself.
